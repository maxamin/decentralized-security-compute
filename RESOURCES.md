- Chen et al., "EnFuzz: Ensemble Fuzzing", USENIX Security 2019

## Confidential computing tooling
- [VirTEE snpguest](https://github.com/virtee/snpguest): fetch and verify AMD SEV-SNP attestation reports
- [Gramine](https://gramine.readthedocs.io): library OS for running unmodified applications in SGX enclaves
- Linux configfs-tsm report interface (see the kernel ABI documentation for configfs-tsm, Linux 6.7 and later)
